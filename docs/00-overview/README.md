# 00-overview

Tato sekce tvoří **vstupní bod do dokumentace ZBNW‑NG**.

Obsahuje dva základní dokumenty, které by měl každý přečíst jako první:

1. **`architecture.md`** — popisuje, co systém obsahuje a jak jsou komponenty propojené.
2. **`terminologie.md`** — definuje pojmy používané napříč celou dokumentací.

Ostatní sekce na tyto dokumenty odkazují jako na autoritativní zdroj pojmů a struktury.

---

## Dokumenty

- [`architecture.md`](architecture.md) — celková architektura systému: komponenty, tok dat, vrstvy
- [`terminologie.md`](terminologie.md) — normativní glosář: zdroj, platforma, post, pipeline, tier
